# Changelog

All notable user-facing changes are recorded in GitHub Releases. As of
`1.0.0`, `cl-weave` follows [Semantic Versioning 2.0.0](https://semver.org/):
releases identify additive (minor), backward-compatible fix (patch), or
intentionally breaking (major) changes, and the version number communicates
compatibility.

See the [release notes](https://github.com/nerima-lisp/cl-weave/releases) for
published versions and the [versioning policy](docs/src/versioning-policy.md)
for compatibility expectations.
